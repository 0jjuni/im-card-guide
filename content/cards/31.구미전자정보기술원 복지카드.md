# 구미전자정보기술원 복지카드

## 기본 정보
| 항목 | 내용 |
|------|------|
| 카드 종류 | 신용카드 |
| 카드 브랜드 | 국내전용(BC) / 국내외겸용(VISA) |
| 연회비 | 국내전용(BC): 2,000원 / 국내외겸용(VISA): 5,000원 (초년도 국내전용 2,000원·국내외겸용 5,000원, 2차년도부터 영구면제) |
| 발급 대상 | 구미전자정보기술원 소속 임직원에 한해 발급 가능 |

## 주요 혜택
상기 할인 서비스(포인트적립 제외)는 전월 신용판매 이용금액 30만원 이상 시 제공. 단, 신규 월 포함 3개월까지는 실적 상관 없이 제공.

| 구분 | 제공 서비스 |
|------|------|
| 연회비면제 | 초년도 국내전용 2,000원 / 국내외겸용 5,000원 (2차년도부터 영구면제) |
| 주유 할인 | SK주유소 L당 60원 청구할인 - 주유 종류: 휘발유, 경유, LPG(경유·LPG는 휘발유 가격에 비례하여 할인 적용) - 1일 2회, 월 4회, 회당 주유금액 10만원 한도 (휘발유 가격은 SK에서 고시하는 휘발유가 기준) |
| 쇼핑 할인 | 롯데마트, 이마트, 홈플러스, CU, GS25 등 5% 청구할인 - 월 1회, 월 합산 최대 5,000원 할인 - 건당 최소 금액 1만원 이상, 최대 10만원까지 |
| 커피 할인 | 드롭탑, 카페베네 10% 청구할인 - 건당 최소 이용금액 1만원 이상, 최대 2만원까지 할인 - 월 2회, 1회 최대 2천원까지 할인(통합할인) - 대형마트, 백화점, 쇼핑몰 입점 점포 제외 |
| 영화 할인 | 롯데시네마 3,000원 청구할인 - 건당 최소 이용금액 1만원 이상, 최대 2만원까지 할인 - 월 2회, 연 6회(통합 할인) - 온라인 발권 제외, 현장할인만 적용 |
| 외식 할인 | 아웃백, 파리바게뜨, 베스킨라빈스 20% 청구할인 - 건당 최소 이용금액 3만원 이상, 최대 5만원까지 할인 - 1회 최대 1만원까지 통합할인 - 월 1회, 연 6회 제공 - 대형마트, 백화점, 쇼핑몰 입점 점포 제외 |
| 포인트적립 | 국내 가맹점 이용실적에 따라 최대 0.3% TOP포인트 적립(해외이용금액·공과금·주유 금액 제외) - 30만원 이상 0.1%, 100만원 미만 0.2%, 100만원 이상 0.3% |
| 교통카드 | 후불 교통카드 발급(신청 회원에 한함) |

## 월간 통합 할인 한도
- 전월 실적 30만원 이상: 할인한도 2만원, 전월 실적 50만원 이상: 할인한도 5만원
- 주유할인을 제외한 부가서비스는 월간통합 할인한도 범위 내 적용됩니다.
- 상기카드의 월간통합할인한도는 전월 이용실적에 따라 변경되며, 익월로 이월되거나 포인트 적립·캐시백 등으로 전환되지 않습니다.

## 유의사항
- 카드 이용시 제공되는 포인트 및 할인 혜택 등의 부가서비스는 카드 신규 출시 이후 3년 이상 축소·폐지 없이 유지됩니다. 상기에도 불구하고 카드사의 휴업·파산·경영상의 위기 등에 따른 불가피한 경우 등 부가서비스를 변경할 수 있습니다.
- 신용카드 발급이 부적정한 경우(연체금 보유, 신용점수 낮음 등) 카드발급이 제한될 수 있습니다.
- 카드이용대금과 이에 수반되는 모든 수수료를 지정된 대금 결제일에 상환합니다.
- 금융소비자는 금소법 제19조제1항에 따라 해당 상품 또는 서비스에 대하여 설명을 받을 권리가 있으며, 그 설명을 듣고 내용을 충분히 이해한 후 거래하시기 바랍니다.
- 카드 신청 전 상품설명서와 약관을 반드시 읽어 보시기 바랍니다.

# 대구경북과학기술원 항공권결제전용카드

## 기본 정보
| 항목 | 내용 |
|------|------|
| 카드 종류 | 법인카드(기업카드) |
| 카드 브랜드 | 국내외겸용(VISA) |
| 연회비 | 국내외 겸용(VISA): 연회비 면제 |
| 발급 대상 | 대구경북과학기술원 기업회원 대상으로 발급 가능 |

## 주요 혜택
- 상기 카드는 국내외 항공권결제전용카드로서 항공권 결제가 많은 기업회원용 카드입니다.
- 이용가능 가맹점은 국내 일반항공사 사용불가하며, 항공권 구입을 국내 항공사업종 및 여행사업종에 한해 가능
- 항공마일리지는 별도로 적립되지 않지만, 항공권 구입시 5% 할인혜택
- 비씨카드사 여행팀 TEL.02-3708-5151 이용 시, 구입 시점 상기카드임을 고지 하셔야 할인혜택 가능합니다.

## 무료 항공여행보험 (보험가입금액)
| 담보종목 | 보험내용 | 보험가입금액 |
|------|------|------|
| 해외여행 중 출국일로부터 90일 이내의 상해사고 | 상해 치료실비 | 최고 1천만원 |
| | 질병 치료실비 | 최고 1천만원 |
| | 법률상 배상책임 | 최고 1백만원 |
| | 휴대품 손해담보 | 최고 1백만원 |
| 해외여행 중 불편(90일 한도) | 연결항공 탑승지연에 따른 직접경비 | 최고 2백만원 |
| | 수하물 지연에 따른 직접경비 | 최고 2백만원 |
| | 수하물 분실에 따른 직접경비 | 최고 2백만원 |
| 국내여행 중 항공기 탑승중 상해 | 법률상 배상책임 | 최고 1백만원 |

- 1사고당 최고 한도보상은 400억원으로 합니다.
- 피보험자의 범위: 상기카드 회원에 적용되는 무료 항공여행보험 보험서비스의 피보험자 범위는 상기카드로 국내외 항공권을 구매한 해당 법인의 임직원 및 동승인으로 합니다. '동승인'이란 회원의 임직원이 아닌 자가 상기카드로 국내외 항공권을 구매하고, 임직원과 동승하는 자를 말합니다. 단, 회원사의 일반 여행객이 여행사 명의 상기카드로 국내외 항공권을 구매한 경우에는 동승인의 피보험자 범위에서 제외됩니다.

## 유의사항
- 카드 이용시 제공되는 포인트 및 할인 혜택 등의 부가서비스는 카드 신규 출시 이후 3년 이상 축소·폐지 없이 유지됩니다. 상기에도 불구하고 카드사의 휴업·파산·경영상의 위기 등에 따른 불가피한 경우 등 부가서비스를 변경할 수 있습니다.
- 신용카드 발급이 부적정한 경우(연체금 보유, 신용점수 낮음 등) 카드발급이 제한될 수 있습니다.
- 카드이용대금과 이에 수반되는 모든 수수료를 지정된 대금 결제일에 상환합니다.

- 카드 신청 전 상품설명서와 약관을 반드시 읽어 보시기 바랍니다.

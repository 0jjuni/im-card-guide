# 경대병원 새마을금고복지카드

## 기본 정보
| 항목 | 내용 |
|------|------|
| 카드 종류 | 신용카드 |
| 카드 브랜드 | 국내전용(BC) / 국내외겸용(VISA) |
| 연회비 | 초년도 국내전용 2,000원, 국내외겸용 5,000원 (2차년도부터 전년도 국내 가맹점 이용실적 30만원 이상 이용 시 1년간 연회비 면제) |
| 발급 대상 | 경대병원 새마을금고 소속 임직원 (단체 발급) |

> 서비스: 전월 30만원 이상 시 서비스 제공되며, 주유할인은 교육 등 이용금액은 전월실적에 미포함됩니다.

## 주요 혜택

| 구분 | 제공 서비스 |
|------|------|
| 연회비면제 | 초년도 국내전용 2,000원, 국내외겸용 5,000원 (2차년도부터 전년도 국내 가맹점 이용실적 30만원 이상 이용 시 1년간 연회비 면제) |
| 주유할인 | 전국 모든 주유소 리터당 최고 60원 청구할인(LPG포함). - 전월 30만원이상~50만원 미만 실적인 경우 리터당 40원, 전월 50만원이상 실적인 경우 리터당 60원 청구할인(주유 실적은 실적에서 제외). - 주유 종류: 휘발유, 경유, LPG (경유, LPG는 휘발유 가격과 비례하여 할인 적용). - 1일 2회, 월 4회, 회당 주유금액 10만원 한도 (휘발유 가격은 SK에서 고시하는 휘발유가 기준) |
| 교육할인 | 전국 학원 및 유치원 업종 10% 청구할인. - 서비스 제공처 통합 월 1회(매출표 접수 순), 월 최대 10,000원 할인. - 대상 업종은 BC가맹점 업종 코드로 구분, 해당 가맹점이 인터넷 결제를 통해 매출 발생시키는 경우 또는 가맹점의 필요에 의해 비씨카드 업종기준과 상이하게 적용시킨 경우는 서비스 제공 불가 |
| 영화할인 | 전국 주요 영화관 3,000원~6,000원 현장할인 및 인터넷 예매 시 청구할인. - 건당 15,000원 이상 금액에 대해 1일 1회, 월 1회, 연간 6회 (15,000원 미만 금액은 3천원 할인) |
| 놀이공원 | 전국 주요 놀이공원 무료입장 및 자유이용권 30~50% 할인. - 놀이공원 전체 통합 월 1회 |
| 외식할인 | 아웃백, 온더보더, VIPS 10% 청구할인. - 월 1회(최대 10,000원), 연 6회, 매출금액 1만원 이상 건 대상, 백화점 및 대형할인점 점포 제외 |
| 통신요금할인 | 이동통신요금 자동이체 시 청구 요금의 3% 할인 (월 1회, 최대 1,500원할인, 최초 접수건에 한해) |
| 교통카드 | 후불 교통카드 발급 (신청 회원에 한함) |

# 대구테크노파크 복지카드

## 기본 정보
| 항목 | 내용 |
|------|------|
| 카드 종류 | 법인카드 (법인형복지카드) |
| 카드 브랜드 | 국내전용 (연회비 영구면제) |
| 연회비 | 국내전용 - 영구면제. 해당 상품은 대구테크노파크 복지 카드 목적으로 발급 가능 |
| 발급 대상 | 제휴업체의 복지비 수혜대상 임직원을 사용지정자로 하는 법인형복지카드 |

## 카드 개요
- 법인형복지카드는 제휴업체의 복지비 수혜대상 임직원을 사용지정자로 하는 법인형복지카드입니다.
- 별도 상품 서비스 없는 비교통카드로, 사용제한업종이 적용되는 클린 카드입니다.
- SMS문자서비스 무료제공.

## 사용제한 업종 (가맹점 업종)
| 구분 | 가맹점 업종 |
|------|------|
| 보건위생 | 이용원, 미용원, 피부미용실, 사우나, 안마시술소, 기타대인서비스 |
| 레져업소 | 골프경기장, 골프연습장, 카지노, 스키장, 헬스클럽, 당구장, 노래방, 기타레져업소 |
| 유흥단란 | 유흥주점, 단란주점 |
| 신변잡화 | 성인용품점 |
| 레저용품 | 총포류판매 |

※ 가맹점 업종 분류는 BC카드 업종 분류 기준을 따르며, 기획재정부 지침에 따라 사용 제한 업종이 변경 및 추가될 수 있습니다.

## 유의사항
- 본 설명서는 「금융소비자 보호에 관한 법률」의 설명의무 이행을 위해 신용카드 설명서 본문과 연계된 설명서로서 제공되는 서류입니다.
